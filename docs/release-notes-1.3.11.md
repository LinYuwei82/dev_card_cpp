## DevCard 1.3.11

### 本次更新

- **修复：自动更新后顶栏残留「有新版本」提示**。此前更新到新版本并重启后，界面上的新版本提示可能持续到下一次后台检查（最长 24 小时）才消失；现在应用启动时即校验本地版本，已追平则立刻收起提示。

### 升级说明

- 1.3.8 / 1.3.9 / 1.3.10 用户可直接点「检查更新 → 下载更新包 → 安装并重启」升级，数据自动保留；升级重启后不会再看到残留的新版本提示。

### 构建与分发

- 本次双平台：构建号 `12`。

### 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| macOS（Apple Silicon） | `devcard-1.3.11-macos-arm64.dmg` | 拖拽到「应用程序」即可 |
| Windows | `devcard-1.3.11-win64-setup.exe` | 安装版 |
| Windows | `devcard-1.3.11-win64-portable.zip` | 免安装绿色版 |

### 校验

随附 `SHA256SUMS.txt`，下载后可自行校验：

```
shasum -a 256 -c SHA256SUMS.txt
```

更新清单使用 Ed25519 签名（`manifest.json`），客户端验签失败会自动放弃本次更新。
