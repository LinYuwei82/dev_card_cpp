DevCard 1.3.8

本次更新

  • 自动更新架构重构：更新判定逻辑全部收口到统一内核，检查节奏、灰度放量、跳过版本、下载与安装编排由服务端统一管理，macOS 与 Windows 壳只负责平台安装动作。历史版本中 mac 与 Windows 各自实现一套更新状态机导致的判定口径不一致问题（同版本重发、灰度 0% 误判、强制更新只提示不拦截等）从根源上消除。
  • 浏览器/mac 路径首次统一受灰度与「跳过此版本」约束：点「跳过此版本」后，在跳过有效期内不再提示同一版本；灰度放量对全部入口一致生效。
  • 启动速度优化：主窗口与启动加载页立即可见，服务端初始化在后台完成，完成后自动进入应用。实测 Windows 首帧约 265ms 降至约 11ms，macOS 约 147ms 降至约 110ms。
  • 修复：运维投放的本地更新清单同样受「跳过此版本」约束；macOS 打印自检在启动流程改造后的回归问题；更新自检请求缺少防跨站头导致的 403。

升级说明

1.3.7 的自动更新链路正常，可直接点「检查更新 → 下载更新包 → 安装并重启」升级到本版本。仍在 1.3.3 / 1.3.4 的用户请先手动覆盖安装一次 1.3.5 或更高版本。

构建与分发

  • 本次双平台：构建号 9。
  • macOS 与 Windows 均从 1.3.7（构建号 8）升级。

校验

随附 SHA256SUMS.txt，下载后可自行校验：

shasum -a 256 -c SHA256SUMS.txt

更新清单使用 Ed25519 签名（manifest.json），客户端验签失败会自动放弃本次更新。
