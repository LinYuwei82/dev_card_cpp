# DevCard 1.4.2

### 本次更新

- **界面更简洁**：Windows 版移除顶部菜单栏，与 macOS 版视觉一致；窗口只剩标题栏与页面本身。
- **「检查更新」入口统一**：底部状态栏版本号右侧新增「检查更新」按钮，Windows / macOS 位置与行为完全一致——立即检查一次，不受 24 小时间隔与「稍后」跳过窗口限制；点版本号本身仍可打开「关于 DevCard」面板。
- **版权署名统一为「小兔在线」**：关于面板、macOS「显示简介」、Windows 文件属性（公司/版权）与「应用和功能」发布者栏全部更新。

### 升级说明

- 1.4.x / 1.3.x 用户可直接点状态栏「检查更新」→「下载更新包」→「安装并重启」升级，数据自动保留。
- 自动更新链路（core `UpdateEngine` + 原生对话框）与 1.4.1 完全一致，无行为变化。

### 构建与分发

- 本次双平台：构建号 `16`。

### 校验

随附 `SHA256SUMS.txt`，下载后可自行校验：

```
shasum -a 256 -c SHA256SUMS.txt
```
