## DevCard 1.3.6

### 本次更新

- **Windows 打印更稳**：打印对话框增加互斥保护，关闭后正确释放，可连续打印不再卡住；导出 Excel 改走浏览器下载通道，保存路径加 Windows 兼容防护；打印内容截断阈值改由服务端统一下发，前后端口径一致。
- **强制更新修复**：静默检查命中强制更新时同样弹窗阻塞，不再只提示不拦截；升级期限改为确定性 UTC 解析，消除不同浏览器判定不一致的问题。
- **更新安全加固**：安装更新包前按发布清单重新校验 SHA256；灰度比例 0% 不再被误判为全量发布；同版本重发的判定与服务端口径对齐；下载完成后及时清理下载记录。
- **登录过期统一处理**：导出、下载模板、上传 Logo 等接口遇到登录过期（401）时统一跳转登录页，不再只报「失败」；Logo 上传增加并发保护与异常兜底。
- **其他修复**：删除设备后清理残留勾选；恢复备份后提示「需要重新登录」；macOS 壳层修复三处内存泄漏并加固单实例防护；服务端修复 xlsx 导入无上限、内部错误信息外泄等问题。

### 升级说明

1.3.5 的 Windows 客户端自动更新链路正常，可直接点「检查更新 → 下载更新包 → 安装并重启」升级到本版本。仍在 1.3.3 / 1.3.4 的用户请先手动覆盖安装一次 1.3.5 或本版本。

### 构建与分发

- 本次双平台：构建号 `7`。
- macOS 从 1.3.4（构建号 `5`）升级；Windows 从 1.3.5（构建号 `6`）升级。

### 校验

随附 `SHA256SUMS.txt`，下载后可自行校验：

```bash
# macOS
shasum -a 256 devcard-1.3.6-macos-arm64.dmg

# Windows
certutil -hashfile devcard-1.3.6-win64-setup.exe SHA256
```
