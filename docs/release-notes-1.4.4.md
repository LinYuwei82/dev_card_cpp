# DevCard 1.4.4

### 本次更新

- **桌面壳内部重构**：Windows 与 macOS 壳按职责拆分为独立模块（窗口宿主、JS 桥、下载与打印通道、更新适配等），行为、界面与数据格式保持不变。
- 服务端与前端无功能变化；本次发布以降低维护成本、为后续改动做准备为主。

### 升级说明

- 1.4.x / 1.3.x 用户可点「检查更新」→「下载更新包」→「安装并重启」升级，数据自动保留。

### 构建与分发

- 本次双平台：构建号 `18`。

### 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| macOS（Apple Silicon） | `devcard-1.4.4-macos-arm64.dmg` | 拖拽到「应用程序」即可 |
| Windows | `devcard-1.4.4-win64-setup.exe` | 安装版 |
| Windows | `devcard-1.4.4-win64-portable.zip` | 免安装绿色版 |

### 校验

随附 `SHA256SUMS.txt`，下载后可自行校验：

```
shasum -a 256 -c SHA256SUMS.txt
```
