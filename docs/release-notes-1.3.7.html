DevCard 1.3.7

本次更新

  • 更新安装失败后可立即重试：Windows 安装接口在准备更新协助程序或写安装状态失败时会复位「正在安装」标志，不再出现重试一直提示安装进行中、必须重启程序才能恢复的情况。
  • 安装结果不串台：安装前清理上一次的安装结果文件，界面不会把旧结果当成本次安装的结果。
  • 质量与自检：清零 macOS 严格告警与 MSVC /W4 编译告警；修正发布自检把构建号误当版本号、把转发包装函数误判为重复实现的问题，避免正常代码被误报。
  • 文档：同步版本键与构建号判据说明。

升级说明

1.3.6 的自动更新链路正常，可直接点「检查更新 → 下载更新包 → 安装并重启」升级到本版本。仍在 1.3.3 / 1.3.4 的用户请先手动覆盖安装一次 1.3.5 或更高版本。

构建与分发

  • 本次双平台：构建号 8。
  • macOS 与 Windows 均从 1.3.6（构建号 7）升级。

校验

随附 SHA256SUMS.txt，下载后可自行校验：

# macOS
shasum -a 256 devcard-1.3.7-macos-arm64.dmg

# Windows
certutil -hashfile devcard-1.3.7-win64-setup.exe SHA256
