DevCard 1.3.9

本次更新

  • 内部存储层重构（无用户可见变化）：数据访问层抽象为统一接口，SQLite 实现收拢到独立后端模块，备份/恢复、迁移与台账读写行为与 1.3.8 完全一致。本次重构为后续网络版（多数据库后端）打基础，功能、界面与数据格式均无变化。

升级说明

  • 本版本没有功能变化，1.3.8 的用户不升级也完全没有影响；如希望保持版本同步，可在 1.3.8 上直接点「检查更新 → 下载更新包 → 安装并重启」。

回归结论

  • 双平台全量单测、备份/恢复、编辑冲突保护（乐观锁）、多实例互斥与心跳、登录限流锁定、xlsx 导入导出、自动更新检查端到端链路全部通过；升级判定与下载校验逻辑未受影响。

构建与分发

  • 本次双平台：构建号 10。
  • macOS 与 Windows 均从 1.3.8（构建号 9）升级。

校验

随附 SHA256SUMS.txt，下载后可自行校验：

shasum -a 256 -c SHA256SUMS.txt

更新清单使用 Ed25519 签名（manifest.json），客户端验签失败会自动放弃本次更新。
