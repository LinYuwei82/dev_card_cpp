DevCard 1.4.6

本次更新

  • 修复 Windows 端「下载模板」与「导出设备台账」没有文件对话框：Windows 壳此前把页面触发的下载静默落到系统「下载」文件夹，用户既看不到保存位置也无法改名。现补上 saveFile 桥，两个入口都会弹出系统保存对话框，默认定位到「下载」文件夹，文件名可自行修改。
  • 选择「取消」不会写出任何文件，也不会误报导出成功；确认后先写同目录临时文件再原子替换，中途失败不会留下半个 xlsx。
  • 成功后面板提示实际保存路径；浏览器访问与旧版壳仍沿用原有下载方式，行为不变。
  • macOS 导出路径不变（原本就是系统保存面板）。数据、接口与打印版式均无变化。

升级说明

  • 直接升级即可，数据自动保留：点顶栏「检查更新」→「下载更新包」→「安装并重启」。
  • 1.4.5 及更早版本均可按正常节奏升级。
