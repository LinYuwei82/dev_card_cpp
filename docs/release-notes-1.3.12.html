DevCard 1.3.12

本次更新

  • 修复：Windows 更新状态文件清理延迟。1.3.11 已消除更新后顶栏残留的「有新版本」提示，但 Windows 上因文件句柄时序，更新状态文件的磁盘清理要拖到下一次后台检查才完成（提示本身启动即消失，不影响使用）。本版在启动校验前先关闭状态文件句柄，状态文件随启动立即清理。

升级说明

  • 1.3.8 / 1.3.9 / 1.3.10 / 1.3.11 用户可直接点「检查更新 → 下载更新包 → 安装并重启」升级，数据自动保留。

构建与分发

  • 本次双平台：构建号 13。

校验

随附 SHA256SUMS.txt，下载后可自行校验：

shasum -a 256 -c SHA256SUMS.txt

更新清单使用 Ed25519 签名（manifest.json），客户端验签失败会自动放弃本次更新。
