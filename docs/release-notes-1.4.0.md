# DevCard 1.4.0

### 本次更新

- **重大变更：自动更新链路重构（mote 化）**。版本检测、清单验签、灰度/跳过/强制更新判定与检查调度全部收进程序内核（Windows / macOS 桌面版共用同一份代码），更新提示改为系统原生对话框；服务端与网页不再参与更新。
- **行为变化**：
  - 页面顶栏的「有新版本」提示、「检查更新」按钮与更新弹窗已移除；浏览器打开的网络版不再提供更新提示与下载入口，需要升级时请使用桌面版或按发布页手动替换。
  - 更新提示不再区分管理员与普通账号：在这台机器上运行桌面版的人都会收到。
  - Windows 安装版：弹窗点「更新」后直接静默安装并按原路径自动重启，不再经过独立的安装协助进程；绿色版下载更新包后自动打开所在文件夹，解压覆盖即可。
  - macOS：原生弹窗确认后由 Sparkle 完成下载、验签、替换与重启（与此前一致，提示改为原生对话框）。
  - 手动检查入口：Windows 菜单栏「帮助 → 检查更新」、macOS 菜单栏「DevCard → 检查更新…」，不受 24 小时间隔与跳过窗口限制。
- 台账功能、数据目录与清单格式（Schema v2，Ed25519 签名）均不变；1.3.x 客户端可按原有方式升级到本版。

### 升级说明

- 1.3.8 / 1.3.9 / 1.3.10 / 1.3.11 / 1.3.12 用户可直接点「检查更新 → 下载更新包 → 安装并重启」升级，数据自动保留；升级到 1.4.0 后，更新提示即为原生对话框。
