稳定版 · 2026-11-19

DevCard v1.2.8

桌面版「退出」真正退出应用；更新检查与清单链路的一轮修复。

重点修复

  • 桌面版点「退出」不再停在登录页：macOS / Windows 客户端点顶栏「退出」直接关闭应用（Windows 会先弹确认框），不再退回登录界面。浏览器 / 网络版仍然是退出登录。
  • 检查更新首次点击不再误报：修复首次点击把网络冷启动误判为「返回数据格式不合法」的问题，第一次点就能拿到正确结果。
  • 远端清单先验签再给资产：WebView 内无法做 Ed25519 验签，改由本地服务端 POST /api/version/verify 验签通过后才下发下载地址，避免验签缺失导致「下载 / 安装」按钮长期置灰。

其他改进

  • 更新清单与 appcast 上传改为 no-cache，发版后客户端不再命中旧清单。
  • Windows 安装包新增桌面快捷方式，开始菜单项保持不变。
  • Windows 导出 / 打印前先过字体闸门，缺字时直接提示，不再输出缺字 PDF。
  • 会话文件落盘后收紧为 0600。
  • 设备分页偏移改用 64 位计算，极端页码不再溢出回绕。
  • 设备路径 id 解析失败返回 404，不再 500 透出内部异常。
  • 导入时必填项缺失只跳过该行，不再整批回滚；xlsx 解压加上尺寸上限。

升级方式

平台方式
macOS应用内「检查更新」，或从下载页重新安装（覆盖安装保留数据）
Windows应用内「检查更新」，或运行新版安装包覆盖安装
台账数据保存在用户数据目录，覆盖安装不会删除；卸载默认保留数据，除非勾选同时清理。
