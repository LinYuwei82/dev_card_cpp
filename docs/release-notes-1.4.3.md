# DevCard 1.4.3

### 本次更新

- **「检查更新」按钮移至顶栏右上角**（版本号左侧），入口更显眼、布局更协调；点击立即检查一次，不受 24 小时间隔与「稍后」跳过窗口限制。Windows / macOS 界面完全一致。
- 其余功能与 1.4.2 相同，无行为变化。

### 升级说明

- 1.4.x / 1.3.x 用户可点「检查更新」→「下载更新包」→「安装并重启」升级，数据自动保留。

### 构建与分发

- 本次双平台：构建号 `17`。

### 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| macOS（Apple Silicon） | `devcard-1.4.3-macos-arm64.dmg` | 拖拽到「应用程序」即可 |
| Windows | `devcard-1.4.3-win64-setup.exe` | 安装版 |
| Windows | `devcard-1.4.3-win64-portable.zip` | 免安装绿色版 |

### 校验

随附 `SHA256SUMS.txt`，下载后可自行校验：

```
shasum -a 256 -c SHA256SUMS.txt
```
